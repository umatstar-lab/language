# Akeeba Backup Professional 10.5.0 для Joomla 6

Русский (`ru-RU`) и украинский (`uk-UA`) переводы подготовлены по
английским файлам из оригинального пакета 10.5.0. Каждый установщик
Joomla содержит 20 INI и 1961 запись для пакета, обеих частей компонента
и восьми плагинов. Два INI без записей сохранены как в оригинале.
Перевод выполнен локальными моделями с выборочной ручной редактурой.

## Установка в Joomla

1. Установите Akeeba Backup Professional 10.5.0 и официальный языковой
   пакет Joomla для нужного языка.
2. Загрузите соответствующий ZIP из `dist/` через
   **Система → Установка → Расширения**.
3. Выберите нужный язык сайта или панели администратора. Оба пакета
   можно установить одновременно.

## Мастер восстановления BRS

Архив `akeebabackup-pro-10.5.0-brs-ru-uk.zip` содержит по три INI на язык
и 450 записей на язык. Он предназначен для уже распакованной копии сайта
перед запуском мастера восстановления.

Скопируйте `brs/installation/language/<язык>.ini` из архива в
`installation/language/` распакованного сайта. Затем скопируйте
`brs-joomla/installation/platform/language/<язык>.ini` в
`installation/platform/language/`. Для универсального профиля BRS
используйте файл из `brs-generic/` вместо файла из `brs-joomla/`.
Откройте мастер восстановления и выберите язык. Пакеты Joomla
предназначены для работающего сайта, а файлы BRS загружает сам мастер.
